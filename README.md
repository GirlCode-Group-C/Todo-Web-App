# 📝 To-Do Web App

## Overview

The **To-Do Web App** is a comprehensive, web-based task management system designed to help users efficiently organize and visualize their daily activities. The application enhances productivity by allowing users to categorize their tasks into three main sections:

* 🏠 **Home To-Do** — Manage personal and household tasks
* 🎓 **School To-Do** — Track academic work, assignments, and deadlines
* 💼 **Work To-Do** — Organize professional and office-related tasks

With multiple visualization options and an intuitive interface, this app streamlines daily task management across different areas of life.

---

## 🚀 Features

* **Task Categorization** — Separate tasks into Home, School, and Work lists.
* **CRUD Operations** — Create, read, update, and delete tasks easily.
* **Status Tracking** — Mark tasks as complete or pending.
* **Responsive Design** — Works seamlessly on desktop and mobile devices.
* **Persistent Storage** — Saves user data using a database backend.
* **Simple Deployment** — Easy to set up locally or deploy on a web server.

---

## 🧰 Technologies Used

* **Backend:** Python (Django / Flask)
* **Frontend:** HTML5, CSS3, JavaScript (and optionally Bootstrap)
* **Database:** SQLite / PostgreSQL (depending on configuration)
* **Version Control:** Git & GitHub

## 🖥️ Getting Started

Follow these steps to set up the project locally on your machine.

### 1. Clone the Repository

```bash
git clone https://github.com/GirlCode-Group-C/Todo-Web-App.git
```

### 2. Navigate to the Project Directory

```bash
cd Todo-Web-App
```

### 3. Create and Activate a Virtual Environment

#### For Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

#### For macOS/Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 4. Install Project Dependencies

Make sure your virtual environment is activated, then install all required packages:

```bash
pip install -r requirements.txt
```

---

## ▶️ Running the Application

After installing dependencies, start the development server.

If this is a **Django** project:

```bash
python manage.py runserver
```

If this is a **Flask** project:

```bash
python app.py
```

Once the server starts, open your browser and go to:
👉 **[http://127.0.0.1:8000](http://127.0.0.1:8000)** (or **[http://127.0.0.1:5000](http://127.0.0.1:5000)** for Flask)
